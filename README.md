# CacheLab

CacheLab est un système de cache clé/valeur développé en TypeScript.

## Objectif

Développer un moteur de stockage en mémoire basé sur une table de hachage implémentée de zéro.

## Technologies

- Node.js
- TypeScript
- API REST
- HashTable personnalisée

## Équipe

Projet réalisé par trois développeurs.
